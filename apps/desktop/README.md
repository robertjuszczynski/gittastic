# @gittastic/desktop

## Cancelling async work across IPC

`AbortSignal` can't be sent over Electron IPC (it's not structured-clonable), so a long-running
main-process operation can't be cancelled by passing a signal from the renderer directly.

Instead, `src/main/registries/abort-registry.ts` keeps the `AbortController` in the main process,
keyed by a `requestId` generated by the caller:

- Wrap the operation: `withAbort(requestId, (signal) => doSomething(..., signal))`
- Cancel it from another IPC call: `abortRequest(requestId)`

The renderer only ever passes the `requestId` around (e.g. via `src/renderer/shared/lib/abort/useAbort.ts`),
never the signal itself.
